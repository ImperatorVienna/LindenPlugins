# 图片查看器

管理 Linden AI 生成图片的本地文件：保存位置、读取与查看，并为对话提供图片缩略图和大图查看。是“图片生成”服务的启用前置。

## 版本信息

- 当前版本：1.0.1
- 模组标识：`linden.image-viewer`
- 更新分支：`image-viewer`

## 功能

- 工作模式生成的图片保存在该工作文件夹的 `generated-images/` 子文件夹；聊天与“图片生成”服务界面生成的图片保存在统一文件夹，默认为系统“图片”目录下的 `Linden AI`，可在模组中更改。
- 按需读取已保存的图片，供对话缩略图与大图查看使用；只读取本模组管理的文件夹。

## 运行要求

需要 Linden AI 客户端：系统图片文件夹由客户端按平台确定后提供给本模组，本模组不含平台相关代码；单独在其他 OpenCode 客户端中加载时，统一文件夹不可用。

## 安装与更新

本模组随 Linden AI 客户端内置，启动时自动安装，在“模组管理”中显示为“内置”，不可删除。本分支发布新版本后，在“模组管理”中点击“刷新”检查更新，有新版本时点击“更新”；更新后以本分支版本为准，客户端不会用内置副本覆盖。更新来源：

```text
git+https://github.com/ImperatorVienna/LindenPlugins.git#image-viewer
```

## 使用方法

无需手动操作。对话中的图片会显示缩略图，点击可查看大图；在“模组管理”中可查看或更改统一图片文件夹。

## 限制与说明

- 支持 PNG、JPEG、WebP，单张不超过 25 MB。
- 删除对话不会删除已保存到磁盘的图片。
