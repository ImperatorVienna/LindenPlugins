# 上下文压缩增强

接管 Linden AI 的上下文压缩：可指定压缩所用的云端模型或在本机用本地模型压缩，保证压缩不会悄悄丢弃较早的对话，压缩失败时在对话中询问下一步。

## 版本信息

- 当前版本：1.0.3
- 模组标识：`linden.context-compaction-enhancement`
- 更新分支：`context-compaction-enhancement`

## 功能

- 压缩所用模型可在模组中设置，默认使用当前对话的模型；可改用当前可用的其他文字生成模型（如更便宜的长上下文模型）。
- 所选模型不可用或上下文不足以读完待压缩内容时，本次改用当前对话的模型；仍然装不下时分段滚动总结，不丢弃任何内容。
- 只总结对话内容：系统提示和工具定义每次请求都以最新原文发送给模型，不写进摘要。
- 压缩失败时原对话保持不变，并在对话中询问：改用当前对话模型重试、分段总结重试或暂不处理。
- 本地压缩：可选标准版 Qwen3 1.7B Q8_0（1.8 GB）或增强版 Qwen3 4B Q4_K_M（2.5 GB），按需从 Qwen 官方 Hugging Face 仓库下载并校验，由模组自带的 llama.cpp 在本机运行；启用后对话内容不发送给云端。本地压缩失败时不会自动改用云端模型，而是询问：重试本地压缩、本次改用云端模型或暂不处理。

## 运行要求

需要 Linden AI 客户端。云端压缩会把对话发送给所选模型的服务商，费用计入你的服务商账户；本地压缩需要约 2–5 GB 可用内存，速度取决于处理器。

## 安装与更新

本模组随 Linden AI 客户端内置，启动时自动安装，在“模组管理”中显示为“内置”，不可删除。本分支发布新版本后，在“模组管理”中点击“刷新”检查更新，有新版本时点击“更新”；更新后以本分支版本为准。更新来源：

```text
git+https://github.com/ImperatorVienna/LindenPlugins.git#context-compaction-enhancement
```

## 使用方法

在“模组管理”中本模组的卡片里点击“管理”，选择云端压缩模型；需要本地压缩时在“本地压缩模型”中选择模型并下载。对话接近模型上下文上限时自动压缩。

## 限制与说明

- 本地引擎随模组按平台构建，当前发布只包含已验证的平台；没有引擎的平台只能使用云端压缩。
- 本地模型以 16K 上下文运行，较长的对话分段滚动总结，可能需要几分钟。
- 上下文长度按文字估算，可能与服务商的实际计数略有差异。

## 文件说明

`index.js` 为插件程序；`package.json` 为包信息；`native/<平台>/llama-server` 为本地压缩引擎。
